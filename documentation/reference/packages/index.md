# Packages

rocketh is a set of small packages: the core, the runtimes that run it, and the extensions a project picks. Each README (what npm shows) says what the package is and how to install and wire it; the guide is where its behaviour is documented.

| Package                                                                                                           | What it is                                                                                                                    | Guide                                                                                                  |
| ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| [`rocketh`](https://github.com/wighawag/rocketh#readme)                                                           | The environment and the executor: runs deploy scripts, saves and reads deployments.                                           | [Deploy scripts](../../deploy-scripts/)                                                                |
| [`hardhat-deploy`](https://github.com/wighawag/rocketh/tree/main/packages/hardhat-deploy#readme)                  | The Hardhat plugin: the `deploy` task, typed artifacts, the network helpers, `hardhat-deploy init`.                           | [hardhat-deploy](/hardhat-deploy/)                                                                     |
| [`@rocketh/node`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-node#readme)                     | The Node.js runtime: the `rocketh` command, and environments built from files.                                                | [Get started without Hardhat](../../getting-started/), [CLI](../cli/#rocketh)                          |
| [`@rocketh/web`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-web#readme)                       | The browser runtime: deploy scripts as modules, records in memory or IndexedDB.                                               | [Run deploy scripts in a browser](../../browser/)                                                      |
| [`@rocketh/deploy`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-deploy#readme)                 | `deploy` and `computeDeterministicAddress`.                                                                                   | [Deploy contracts](../../deploy-contracts/), [Deterministic addresses](../../deterministic-addresses/) |
| [`@rocketh/read-execute`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-read-execute#readme)     | `read`, `execute` (with its `guard`), `tx`.                                                                                   | [Guard execute calls](../../execute-guard/)                                                            |
| [`@rocketh/proxy`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-proxy#readme)                   | `deployViaProxy`: ERC-173, UUPS and transparent proxies.                                                                      | [Proxies](../../proxies/)                                                                              |
| [`@rocketh/diamond`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-diamond#readme)               | `diamond`: EIP-2535 diamonds.                                                                                                 | [Diamonds](../../diamonds/)                                                                            |
| [`@rocketh/router`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-router#readme)                 | `deployViaRouter`: one entry point over several route contracts.                                                              | [Routers](../../routers/)                                                                              |
| [`@rocketh/unknown-signer`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-unknown-signer#readme) | `withUnknownSignerPolicy`, the policy for one call from a Safe or a multisig, and `catchUnknownSigner` for ported v1 scripts. | [Unknown signers](../../unknown-signers/)                                                              |
| [`@rocketh/signer`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-signer#readme)                 | The `privateKey` signer protocol.                                                                                             | [Named accounts and signers](../../named-accounts/#signer-protocols)                                   |
| [`@rocketh/viem`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-viem#readme)                     | viem clients and typed contracts for your deployments.                                                                        | [Use viem](../../viem/)                                                                                |
| [`@rocketh/export`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-export#readme)                 | `rocketh-export`: deployments as one file for a frontend.                                                                     | [Export](../../exporting-and-verifying/#exporting-deployments)                                         |
| [`@rocketh/verifier`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-verifier#readme)             | `rocketh-verify`: source verification on Etherscan, Sourcify and Blockscout.                                                  | [Verify](../../exporting-and-verifying/#contract-verification)                                         |
| [`@rocketh/doc`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-doc#readme)                       | `rocketh-doc`: documentation from ABIs and NatSpec.                                                                           | [Document](../../exporting-and-verifying/#generating-documentation)                                    |
| [`@rocketh/core`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-core#readme)                     | The shared types and utilities, for extension authors.                                                                        | [Extending rocketh](../../extending/)                                                                  |
| [`@rocketh/test-utils`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-test-utils#readme)         | A real environment over a mock provider, for testing extensions.                                                              | [Testing an extension](../../extending/testing/)                                                       |
| [`@rocketh/playground`](https://github.com/wighawag/rocketh/tree/main/packages/rocketh-playground#readme)         | The in-browser playground of this site, as a widget.                                                                          | [Introduction](../../#try-it-here)                                                                     |

A project needs `rocketh`, a runtime (`@rocketh/node`, which hardhat-deploy uses too, or `@rocketh/web`) and the extensions its scripts call; `@rocketh/deploy` and `@rocketh/read-execute` are in almost every project.
